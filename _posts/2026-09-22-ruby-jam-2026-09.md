🚚 忘掉 API，Rails + Inertia.js + React 讓你快速出貨 🚚

為應付現代多端需求爆炸及使用者互動的提升，主流網頁架構多已走向前後端分離的 SPA，雖提升了使用者體驗及多端共用彈性，但也讓小團隊在快速開發、POC 驗證階段顯得笨重(?)，光串一支 API 就耗掉大半時間。

Inertia.js 提供中間路線：讓 Rails 工程師不寫獨立 API，也能用 React 畫面直接出貨，兼具 SPA 操作體驗與 MVC 開發速度。

本場演講將分享 Rails + Inertia.js + React 的實際開發流程，比較前後端分離的差異，並從前端的觀點聊聊優缺點與適用場景。

🦑 RubyKaigi 2026 經驗分享：會場亮點 & 志工幕後！ 🦑

日本 RubyKaigi 是國際指標性的 Ruby 程式語言研討會，每年春季在不同城市舉行，全球 Rubyist 齊聚一堂，參與頂尖技術演講、各種有趣的攤位互動，以及豐富的交流活動🥂

（想像一下，一起賞櫻花、泡溫泉、吃鮪魚、聊聊技術與生活的 #rubyfriends，竟然就是 Ruby 語言的 committer 、重要 gem 的 contributor！）

今年台灣社群有不少夥伴前往函館參與，大家分別以閃電講者、工作人員、參加者等不同角度，體驗了這場盛會。Kasa 將以第一次擔任工作人員的經驗起頭，並帶大家一起聊聊今年的 Kaigi 會場見聞！

距離 RubyKaigi 2027 剛好還有半年的時間，無論是準備投稿演講、規劃赴日行程、或是對幕後志工有興趣，是時候開始了解囉！期待明年在宮崎見到大家！
