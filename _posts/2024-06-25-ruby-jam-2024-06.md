Ruby Jam 2024/6 月場（2024/06/25・台北市大安區光復南路102號3樓）的分享內容如下。

(1) Ruby Gem 開源貢獻指南

講者：蒼時弦也

講者簡介：程式語言愛好者，主要使用 Ruby/Go 語言，認為軟體開發也能具備美感，正在尋找滿足敏捷、架構與享受開發過程之間的平衡點。

主題簡介：從上個月的活動中我們發現多數與會者希望能夠參與 Ruby 開源專案，但往往不知道如何開始，不知道怎麼快速了解專案 codebase，亦或是要怎麼找到適合送 PR 的主題。講者將以 hanami-lambda 為例，講解如果想要開源貢獻可以從何下手。

(2) （續上月）Live Coding：將 CRuby on Rails 專案快速轉移到 JRuby on Rails

講者：Mu-Fan Teng

講者簡介：日卡與 Ruby 愛好者，立志成為製造最多 Bug 的人

主題簡介：

上個月我們將試著把 RubyConf Taiwan 的 CFP 專案，從 CRuby 轉到 JRuby。因為時間關係沒辦法完成，因此我們會在這個月繼續 Live Coding 展示如何能轉移到能跑完測試、部署執行。

【什麼是 Ruby Jam】

Ruby Jam 是 Ruby 社群每月一次的技術交流聚會，以「主題技術分享」 + 「閃電秀」 + 「交流」的形式呈現，希望能幫助 Ruby 圈的各方人士達到所追求的目的。

不管你是遇到問題想求人解惑，還是有很讚的技術研究和經驗想要分享給社會大眾，又或是想來認識新朋友增加人脈，這正是個夢寐以求的場合！

若你是正要接觸 Ruby 的初心者，也歡迎來 Ruby Jam 看看。
