Ruby Jam 2025/09 月場（2025/09/30・台北市大安區光復南路102號3樓）的分享內容如下。

🔥 Divide and Conquer with Claude Code and git worktree 🔥

講者：Aleksandr Kunin

Writing Ruby at work. Writing Ruby in my free time. Hotwire over React. Share DHH ideas on how to write software well. Creator of skyderby.io - like Strava but for skydivers and base jumpers.

簡介：

在工程領域中，善用 AI 提升產出已經成為熱門話題。近期 Aleks 深入研究並實際應用 Claude Code，累積了豐富的實戰經驗。他將在 9 月的 Ruby Jam 中分享如何透過 Claude Code 將任務與挑戰逐一擊破，展現「分而治之」的高效率技巧。

此外，Aleks 也將介紹 git worktree ——一個雖然存在已久、卻鮮為人知的功能。它或許是你過去10 年來未曾碰過的指令，卻可能成為你明日提升效率的利器。

在新技術與經典工具之間靈活切換，Aleks 的分享必將帶來啟發與實用技巧。讓我們一起期待這場精彩的交流！
