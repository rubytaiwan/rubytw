🚂 Hotwire Native 實作筆記：跨過 Hello World 之後，才是真正的挑戰開始 🚂

Hotwire Native 讓 Rails 工程師不用另外學 React Native 或 Flutter，就能把現有的網站包裝成 iOS / Android App。但官方教學通常停在「載入一個網頁」的程度——真正動手做一個堪用的 App，會遇到教學裡沒寫的東西：Bridge Component 怎麼把webview的漢堡選單變成原生選單、原生header還可以做什麼變化、Tab Bar 底下每個分頁如何各自管理自己的導覽堆疊...等。

這場分享會從我在 Rails 專案上實作 Hotwire Native 的真實過程出發，記錄從「照著教學做出一個能動的殼」到「做出一個可以完整體驗、導覽的 App」之間，中間補上的那些細節與踩過的坑，也會提到身為 Rails 工程師，在跨進 iOS 原生世界（Swift / SwiftUI）時遇到的真實技術衝突與解法。適合對 Hotwire Native 有興趣、想知道更多關於實作上的細節的 Rails 工程師。

🏇 AI Harness Evolution. Even More Everyday Productivity 🏇

Aleks is a seasoned Rubyist who has spent recent years bringing AI agents into day-to-day Rails development. Using real Ruby/Rails projects, he'll walk through the workflow he has refined over time:

One worktree per area of the codebase, not per task: each agent keeps long-lived context on its own domain, and agents talk to each other.

Let the agent work while you're away: come back to a screencast showing what it did.

PR stacks for faster reviews: break large changes into small PRs that can be reviewed in order, with GitHub-native Mermaid diagrams to explain the architecture.
