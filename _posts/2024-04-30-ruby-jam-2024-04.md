Ruby Jam 2024/4 月場（2024/04/30・台北市大安區光復南路102號3樓）的分享內容如下。

(1) Ruby on the Modern JVM with JRuby

講者：Charles Nutter

講者簡介：Charles works on JRuby and JVM languages at Red Hat

主題簡介：

JRuby 從過去到現在一直是開發 Ruby 的優秀選擇，在垃圾回收(garbage collection)、即時編譯(JIT compilation)、並行架構(concurrency)都帶給開發者極好的體驗。隨著 Java 22 的發布，現在更有了原生 Fiber、更快速的 native function 和 memory support。這次講座，Charles 將向大家展示 JRuby 的魅力之處，讓大家展開一場精彩絕倫的 JRuby 之旅。

(2) RubyConf AU 見聞

講者：Mu-Fan Teng

講者簡介：日卡與 Ruby 愛好者，立志成為製造最多 Bug 的人

主題簡介：

本講題將介紹講者參加 RubyConf AU 的所見所聞，在過程中發生的有趣的事情、發現的新事物等等，為大家敞開視野，感受在異國 Ruby 研討會的各種遊歷。

【什麼是 Ruby Jam】

Ruby Jam 是 Ruby 社群每月一次的技術交流聚會，以「主題技術分享」 + 「閃電秀」 + 「交流」的形式呈現，希望能幫助 Ruby 圈的各方人士達到所追求的目的。

不管你是遇到問題想求人解惑，還是有很讚的技術研究和經驗想要分享給社會大眾，又或是想來認識新朋友增加人脈，這正是個夢寐以求的場合！

若你是正要接觸 Ruby 的初心者，也歡迎來 Ruby Jam 看看。
