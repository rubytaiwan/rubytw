Ruby Jam 2026/03 月場（2026/03/17・台北市大安區光復南路102號3樓）的分享內容如下。

🪖 用 Claude Code 組一個 ATDD 開發小隊 — Rails 專案導入經驗 🪖

用 Claude Code 的機制，組建一個由 7 個 Agent 組成的團隊，各自負責需求分析、測試、實作、審查與知識管理。透過 HITL 在每階段設置關卡，由人類決策把關交付物。隨著任務不斷推進，領域知識在過程中累積，逐步成爲一套的商業知識體系。

講者

Wayne 誌維

😈 你升版了嗎？談談 Ruby 3 的 ReDoS 防禦設計 😈

「每次提起升版就被已讀。」

WebConf 2025 Huli 的演講重燃大家對 ReDoS 的關注，那 Ruby 圈是如何應對此安全性議題呢？

2022 年底，Ruby 3.2 大幅改善了 Regexp 的安全性與效能；隨著 Ruby 4 發佈、Ruby 3.2 即將進入 EOL，來談談 #17837 與 #19104 的設計與權衡，以及為何在 2026 更應重視 ReDoS 議題。

講者

Kasa

🤝 Become Friends with Your Coding Agent 🤝

By speaking same language coding agent can do so much for you, you will want to hug it. This talk is a mix of theory and practice in the context of Ruby on Rails development. To make you achieve more in your day-to-day work.

講者

Aleksandr Kunin
