📚 Ruby 文件的未來 📚

RDoc 是 Ruby 文件體系的骨幹：它支撐了 docs.ruby-lang.org、ri 指令列工具，以及所有 Gem 的 API 文件。然而，它逐漸跟不上現代 Ruby 的演進、現代 Markdown 的標準，以及現今開發者（甚至 AI Agent）查閱文件的方式。

在過去兩年中，我們重構了其核心組成：

基於 Prism 的全新 Parser

名為 Aliki 的新預設主題

更完善的 Markdown 支援

在 HTML 與 ri 中整合 RBS type signatures

Live-preview server

這些功能有的已經發布，有的則即將在 RDoc 8.0 中登場。

這場 Talk 將涵蓋我們已完成的成果，以及接下來的計畫；特別是為什麼 Ruby 文件系統也必須為 AI 時代做好準備。
